# Changelog

## 1.1.0 — Security and packaging refresh (2026-11-19)

- Consolidated standalone decoder and Colab notebook under version-neutral filenames.
- Hardened input size caps, decompression limits, malformed HTTP chunk handling, output safety, terminal-log escaping, and diagnostic redaction.
- Blocked vulnerable Brotli versions prior to 1.2.1 (CVE-2026-111497).
- Expanded synthetic multilingual and security-focused unit tests.
- Added security policy, review report and pinned read-only GitHub Actions workflow.
- Preserved English-first README with Traditional and Simplified Chinese translations.
